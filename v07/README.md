# SMR Alpine v0.7 — Stage III: Skier & Carving

**Play on Android:** https://pchojnowsky-stack.github.io/smr-pixel-ski/v07/

- Separate stage: prior `/`, `/v05/`, `/v06/` preserved.
- New self-contained `skier.js` creates an original procedural, articulated 3D skier (PBR materials, rounded anatomy, helmet, goggles, skis, bindings, poles, backpack).
- Lean into carves, coordinated arm and knee motion, skiing/braking poses.
- Bounded snow spray particle system tied to skier's world position.
- Twin ski tracks, speed and time remain functional.
- Staging screenshot smoke test uses real browser/WebGL at 1280×720 and 390×844.

**Not yet photorealistic or identical to concept C:** This is a procedural placeholder for a final artist-authored rigged glTF model. Terrain is not a surveyed map of SMR. CI FPS is from software rendering and does not predict Android hardware performance.
